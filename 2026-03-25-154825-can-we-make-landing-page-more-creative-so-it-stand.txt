⏺ ★ Insight ─────────────────────────────────────
  SEO for single-page developer tools:
  - JSON-LD SoftwareApplication schema is the most impactful structured data for
   dev tools — it tells Google this is downloadable software with a license,
  requirements, and install URL, which can trigger rich results
  - OG image as SVG works on most platforms (Twitter, Slack, Discord) but some
  crawlers prefer PNG. If you later deploy to GitHub Pages, consider converting
  to PNG for broader compatibility
  - summary_large_image Twitter card type shows the full-width image preview —
  critical for developer tools where the visual makes the first impression
